# Task

This directory has 4 package folders: `pkg_alpha/`, `pkg_beta/`, `pkg_gamma/`,
`pkg_delta/`. Each holds a `core.py`.

Write a `README.md` inside each of the 4 folders. Each README must:
- start with a level 1 heading holding the folder name
- list every public function of that folder's `core.py` (a name that does not
  start with an underscore) as a markdown bullet that starts with the
  function name in backticks, followed by a short description taken from its
  docstring
- not mention any private function (a name that starts with an underscore)

Do not change any `core.py`. Only create the 4 README files.
