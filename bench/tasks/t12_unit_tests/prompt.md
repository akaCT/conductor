# Task

This directory has 4 modules: `m_stack.py`, `m_slug.py`, `m_ranges.py`,
`m_money.py`.

For each module write a test file named `test_<module>.py` (so `test_m_stack.py`,
`test_m_slug.py`, `test_m_ranges.py`, `test_m_money.py`) using the standard
library `unittest`. Each test file must:
- import the module it tests by its plain name (for example `import m_stack`)
- hold at least 3 test methods
- pass when run with `python3 -m unittest test_<module>`
- fail if the module's behavior is broken

Do not change the 4 modules. Only create the 4 test files.
